📖 كيف يعمل ZONE TUNNEL؟
  1. أنشئ مفتاح API خاص بك من صفحة مفاتيح API
  2. أنشئ نفقاً من صفحة الأنفاق النشطة
  3. شغّل سكربتك المحلي على منفذ (مثلاً 5000)
  4. شغّل أمر zone client الذي سيظهر لك
  5. شارك رابط النفق مع أي شخص ليصل لسكربتك
🔑 مفاتيح API
استخدم هذه المفاتيح لربط سكربتاتك بالمنصة
📖 كيف تستخدم مفتاح API؟
دليل سريع لربط سكربتك بالمنصة
🌐 عنوان السيرفر (Base URL)
هذا هو العنوان الذي سيتصل به سكربتك في كل الطلبات
🔑 طريقة الاستخدام
أرسل كل الطلبات بطريقة POST مع تمرير المفتاح داخل جسم الطلب باسم _token والمحتوى من نوع text/plain;charset=UTF-8
🐍 مثال بلغة Python
import requests

API_URL = "https://pedigree-hankering-unmixable.ngrok-free.dev"
API_KEY = "ضع_مفتاحك_هنا"

headers = {
    "Content-Type": "text/plain;charset=UTF-8",
    "ngrok-skip-browser-warning": "true"
}

response = requests.post(
    API_URL + "/api/user/me",
    headers=headers,
    json={"_token": API_KEY}
)
print(response.json())
🌐 مثال بلغة JavaScript
const API_URL = "https://pedigree-hankering-unmixable.ngrok-free.dev";
const API_KEY = "ضع_مفتاحك_هنا";

fetch(API_URL + "/api/user/me", {
    method: "POST",
    headers: {
        "Content-Type": "text/plain;charset=UTF-8",
        "ngrok-skip-browser-warning": "true"
    },
    body: JSON.stringify({ _token: API_KEY })
})
.then(r => r.json())
.then(data => console.log(data));
💡 ملاحظات مهمة
  • كل الطلبات يجب أن تكون بطريقة POST فقط.
  • لا تشارك مفتاحك مع أي شخص — من يملكه يستطيع التحكم بحسابك.
  • إن واجهت مشكلة في ngrok أضف الهيدر ngrok-skip-browser-warning: true.

🚀 الخطوات — من الصفر للتشغيل

1 أنشئ مفتاح API
من صفحة مفاتيح API، اضغط "إنشاء مفتاح". هذا المفتاح يستخدم للتحقق من هويتك. احفظه في مكان آمن لأنك لن تراه مرة أخرى.
⚠️
لا تشارك هذا المفتاح مع أي شخص. من يملكه يستطيع التحكم بحسابك.
2 أنشئ نفقاً
من صفحة الأنفاق النشطة، اضغط "إنشاء نفق". اختر:
📝 الاسم: أي اسم (مثال: "موقعي")
🔌 المنفذ المحلي: المنفذ اللي يشتغل عليه سكربتك (مثلاً 5000)
بعد الإنشاء، راح يظهرلك:
Tunnel ID: 1
Token: tun_f5iLTIYUCW4GsTrHxGFhYRPx1sbk1EpBWrt7hA53QTs
Local Port: 5000
Public URL: https://.../t/abc123/
🔒
احتفظ بالـ Token و ID و Public URL — راح تحتاجها في الخطوات القادمة.
3 شغّل سكربتك المحلي
أي سكربت HTTP عادي يعمل. هذا مثال بسيط بلغة Python — انسخه واحفظه في ملف my_server.py: 
# my_server.py
from http.server import BaseHTTPRequestHandler, HTTPServer

class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        body = "أهلاً من سكربتي المحلي! 🎉".encode()
        self.send_response(200)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def log_message(self, *a): pass

print("✅ سكربتي يعمل على http://localhost:5000")
HTTPServer(("0.0.0.0", 5000), Handler).serve_forever()
شغّله: 
python my_server.py
✅
سترى: سكربتي يعمل على http://localhost:5000

🐍 سكربت Python كامل يربط تلقائياً
بديل كامل مبسط — لا يحتاج httpx ولا أي مكتبة خارجية. فقط Python خالص.
💡
هذا سكربت جاهز للاستخدام المباشر — انسخه في ملف، عدّل 3 متغيرات في الأعلى، وشغّله. يقوم بكل شي تلقائياً: يسجّل نفسه، يسحب الطلبات (polling)، ينفذها على سكربتك المحلي، ويرجّع الردود.
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
zonetunnel.py — عميل ZONE TUNNEL مبسّط
يربط سكربتك المحلي بالإنترنت عبر نفق ZONE TUNNEL.

الاستخدام:
    1. عدّل المتغيرات الثلاثة في الأسفل (API_URL, TUNNEL_ID, TOKEN, LOCAL_PORT)
    2. شغّل: python zonetunnel.py

ملاحظات:
    - لا يحتاج أي مكتبة خارجية (يستخدم urllib من Python القياسية)
    - يستخدم Long-Polling عبر HTTPS — يعمل خلف أي جدار ناري
"""

import json
import time
import base64
import signal
import sys
import urllib.request
import urllib.error
from http.client import HTTPConnection


# ═══════════════════════════════════════════════════════
# 🔧 الإعدادات — عدّلها من هنا فقط
# ═══════════════════════════════════════════════════════
API_URL    = "https://pedigree-hankering-unmixable.ngrok-free.dev"
TUNNEL_ID  = 1
TOKEN      = "tun_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
LOCAL_HOST = "127.0.0.1"
LOCAL_PORT = 5000
POLL_TIMEOUT = 25  # ثواني — كم ينتظر السيرفر قبل ما يرد "لا جديد"


# ═══════════════════════════════════════════════════════
# أدوات مساعدة
# ═══════════════════════════════════════════════════════
HEADERS = {
    "Content-Type": "text/plain;charset=UTF-8",
    "ngrok-skip-browser-warning": "true",
    "User-Agent": "ZoneTunnelClient/1.0"
}


def api_post(path, payload, timeout=60):
    """يرسل طلب POST لـ API ZONE TUNNEL ويرجع JSON"""
    url = API_URL.rstrip("/") + path
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8")
    req = urllib.request.Request(url, data=data, headers=HEADERS, method="POST")
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            raw = resp.read().decode("utf-8")
            return resp.status, json.loads(raw) if raw else {}
    except urllib.error.HTTPError as e:
        return e.code, {"error": e.read().decode("utf-8", errors="replace")[:300]}
    except Exception as e:
        return 0, {"error": str(e)}


def log(msg, icon="ℹ️"):
    """طباعة منسقة"""
    t = time.strftime("%H:%M:%S")
    print(f"[{t}] {icon}  {msg}", flush=True)


# ═══════════════════════════════════════════════════════
# تنفيذ الطلب محلياً على السكربت
# ═══════════════════════════════════════════════════════
def forward_to_local(method, path, headers, body_bytes):
    """يرسل الطلب لسكربتك المحلي ويرجع (status, headers, body)"""
    # احذف هيدرات ممنوعة
    clean = {k: v for k, v in headers.items()
             if k.lower() not in ("host", "content-length", "connection",
                                   "transfer-encoding", "keep-alive")}

    conn = HTTPConnection(LOCAL_HOST, LOCAL_PORT, timeout=60)
    try:
        conn.request(method, path, body=body_bytes, headers=clean)
        resp = conn.getresponse()
        data = resp.read(10 * 1024 * 1024)
        resp_headers = {k: v for k, v in resp.getheaders()
                        if k.lower() not in ("transfer-encoding", "connection",
                                              "content-length", "content-encoding")}
        return resp.status, resp_headers, data
    finally:
        try: conn.close()
        except: pass


# ═══════════════════════════════════════════════════════
# الحلقة الرئيسية — Polling
# ═══════════════════════════════════════════════════════
running = True


def stop_handler(sig, frame):
    global running
    log("إيقاف...", "🛑")
    running = False


def poll_once():
    """يسحب طلب واحد من السيرفر (Long-Polling)"""
    status, data = api_post(
        "/api/tunnel/poll",
        {"type": "poll", "ts": time.time()},
        timeout=POLL_TIMEOUT + 10
    )
    return status, data


def handle_request(req):
    """ينفذ طلب وارد على السكربت المحلي ويرجّع الرد"""
    req_id  = req.get("id") or req.get("request_id")
    method  = req.get("method", "GET")
    path    = req.get("path", "/")
    headers = req.get("headers", {}) or {}
    body_b64 = req.get("body", "")

    body = base64.b64decode(body_b64) if body_b64 else None

    log(f"→ {method} {path}", "📥")

    try:
        status, resp_headers, resp_body = forward_to_local(method, path, headers, body)
    except Exception as e:
        log(f"خطأ في السكربت المحلي: {e}", "❌")
        resp_body = json.dumps({
            "error": str(e),
            "hint": f"هل سكربتك يعمل على {LOCAL_HOST}:{LOCAL_PORT}؟"
        }).encode()
        resp_headers = {"Content-Type": "application/json; charset=utf-8"}
        status = 502

    log(f"← {status}  ({len(resp_body)}B)", "✅")

    # أرسل الرد للسيرفر
    api_post("/api/tunnel/respond", {
        "req_id": req_id,
        "status": status,
        "headers": resp_headers,
        "body": base64.b64encode(resp_body).decode()
    })


def main():
    print("═" * 60)
    print("  🚀 ZONE TUNNEL Client — مبسّط")
    print("═" * 60)
    print(f"  🌐 Gateway:   {API_URL}")
    print(f"  🚇 Tunnel ID: #{TUNNEL_ID}")
    print(f"  🎯 Local:     http://{LOCAL_HOST}:{LOCAL_PORT}")
    print("═" * 60)

    signal.signal(signal.SIGINT, stop_handler)
    signal.signal(signal.SIGTERM, stop_handler)

    # فحص النفق أولاً
    log("فحص النفق...", "🔍")
    code, resp = api_post("/api/tunnel/check", {
        "tunnel_id": TUNNEL_ID, "token": TOKEN
    })
    if code != 200:
        log(f"فشل الفحص: HTTP {code} — {resp}", "❌")
        return
    if isinstance(resp, dict) and resp.get("tunnel"):
        t = resp["tunnel"]
        log(f"النفق ملكنا: #{t.get('id')} — {t.get('name', '')}", "✅")
    else:
        log(f"رد غير متوقع: {resp}", "⚠️")

    log("بدأ السحب (Polling)... اضغط Ctrl+C للإيقاف", "🎯")
    print("─" * 60)

    # الحلقة الرئيسية
    errors = 0
    while running:
        try:
            status, data = poll_once()

            if status == 200 and isinstance(data, dict):
                # فُكّ الغلاف
                payload = data.get("data") or data
                if isinstance(payload, str):
                    # قد تكون مشفرة بـ base64 — تجاهلنا هنا لأننا مبسطين
                    payload = json.loads(base64.b64decode(payload))

                if payload.get("type") == "request":
                    errors = 0
                    handle_request(payload)
                else:
                    # idle — لا جديد
                    pass
            else:
                errors += 1
                log(f"poll HTTP {status}: {str(data)[:100]}", "⚠️")
                time.sleep(min(2 ** errors, 30))

        except KeyboardInterrupt:
            break
        except Exception as e:
            errors += 1
            log(f"استثناء: {type(e).__name__}: {e}", "❌")
            time.sleep(min(2 ** errors, 30))

    log("انتهى", "👋")


if __name__ == "__main__":
    main()
🎯 ما يفعله السكربت:
1️⃣ يتحقق من صحة النفق عبر /api/tunnel/check
2️⃣ يدخل في حلقة Long-Polling دائمة على /api/tunnel/poll
3️⃣ لما يجي طلب، ينفذه على سكربتك المحلي (127.0.0.1:5000)
4️⃣ يرجّع الرد للسيرفر عبر /api/tunnel/respond
5️⃣ يعيد الكرّة — للأبد، بدون تدخل منك

❓ أسئلة شائعة
العميل يقول "النفق مشغول" — ماذا أفعل؟
يعني عميل آخر متصل بنفس النفق. نفق واحد = عميل واحد. افتح صفحة الأنفاق، أنشئ نفقاً جديداً، واستخدم أمره. أو أوقف العميل القديم أولاً.
يفتح الرابط ويقول "tunnel not found" — لماذا؟
الـ slug في الرابط غير موجود بقاعدة البيانات. تأكد من نسخ الرابط الكامل من صفحة الأنفاق النشطة بدقة.
"tunnel offline" عند فتح الرابط — لماذا؟
العميل (zonetunnel.py) غير شغال على جهازك. شغّله في Terminal واتركه مفتوحاً. سيصبح النفق online خلال ثوانٍ.
ngrok يعرض صفحة تحذير ERR_NGROK_6024 — هل هذا خطأ؟
لا، هذه صفحة ngrok يظهرها مرة واحدة لأول زيارة. اضغط زر "Visit Site" وستنتقل لصفحتك. العميل يضيف الهيدر تلقائياً، فلا تظهر له.
"Connection refused" من العميل — لماذا؟
يعني سكربتك المحلي غير شغال على المنفذ اللي أدخلته. تأكد أن python my_server.py شغال في Terminal آخر، وأنه يستمع على نفس المنفذ.
كيف أتأكد أن النفق يعمل؟
3 فحوصات: (1) نقطة خضراء بجانب النفق في صفحة الأنفاق النشطة. (2) العميل يطبع ✅ بدأ السحب. (3) افتح الرابط العام — يفترض تظهر صفحتك.
هل يعمل على شبكات الشركات/الجدار الناري؟
نعم، طالما يسمح بالخروج على HTTPS (منفذ 443). كل الاتصالات عادية على نفس المنفذ، ما يحتاج فتح أي بورت إضافي.
هل يمكن تشغيل أكثر من عميل لنفس النفق؟
لا. نفق واحد = عميل واحد. إذا احتجت أجهزة متعددة، أنشئ نفقاً لكل جهاز.
هل يمكن تشغيل أكثر من نفق من نفس الجهاز؟
نعم — افتح Terminal جديد لكل نفق، واستخدم أمر تشغيل مختلف لكل واحد. تأكد أن كل نفق يشير لمنفذ مختلف لسكربت مختلف.

  • 🔒 لا تشارك التوكن (tun_...) مع أي شخص — من يملكه يسيطر على نفقك.
