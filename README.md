## نظرة عامة

**ZONE TUNNEL** منصة غير ربحية تمنحك رابطاً عاماً للوصول إلى سكربت أو خادم يعمل على جهازك المحلي. بدلاً من شراء خادم مدفوع أو إعداد قواعد الشبكة يدوياً، تمنحك المنصة رابطاً جاهزاً يمكنك مشاركته مع أي شخص، ليعمل سكربتك كأنه مستضاف على الإنترنت.

المنصة موجّهة للمطورين، الهواة، والشركات. لا تطلب بطاقة بنكية، ولا تعرض إعلانات، ولا تبيع بيانات المستخدمين.

---

## المميزات

**سريع**

بنية تحتية موزعة على أكثر من عشرة مواقع لضمان أقل زمن استجابة ممكن.

**آمن**

جميع الاتصالات مشفّرة عبر TLS 1.3، ومحمية من هجمات الوسيط (MITM).

**بدون حدود**

لا يوجد حد على عدد الطلبات، حجم البيانات، أو عدد الأنفاق النشطة.

**سهل الاستخدام**

واجهة بسيطة، وتكامل عبر سطر واحد في سكربتك.

**غير ربحي**

لا إعلانات، لا رسوم خفية، لا بيع بيانات.

**مفتوح للجميع**

سواء كنت مطوراً محترفاً أو هاوياً أو شركة، الكل مرحب به.

## إنشاء مفتاح API

مفتاح API هو وسيلة المصادقة بين سكربتك والمنصة. يُستخدم في كل طلب تقوم به للتأكد من هويتك.

**خطوات الإنشاء:**

1. سجّل الدخول إلى لوحة التحكم.
2. افتح صفحة "مفاتيح API".
3. اضغط زر "إنشاء مفتاح".
4. أعط المفتاح اسماً يعبّر عن الغرض منه.
5. انسخ المفتاح فوراً واحفظه.

**تنبيهات مهمة:**

- لا تشارك مفتاح API مع أي شخص.
- كل مفتاح خاص بحسابك وحده.
- عند حذف مفتاح، تتوقف كل الأنفاق المرتبطة به.
- يمكنك إنشاء عدة مفاتيح لأغراض مختلفة.

## ربط السكربت

### Python

```python
import requests
import time

API_KEY  = "zt_live_xxxxxxxxxxxxxxxx"
ZONE_URL = "https://your-zone-url"
PORT     = 3000

# إنشاء النفق
r = requests.post(f"{ZONE_URL}/api/tunnels/register", json={
    "api_key": API_KEY,
    "local_port": PORT,
    "name": "My Script"
})
data = r.json()

if not data.get("success"):
    print("فشل:", data.get("detail"))
    exit(1)

public_url = data["tunnel"]["url"]
slug       = data["tunnel"]["slug"]
print("رابطك العام:", public_url)

# إبقاء النفق نشطاً
try:
    while True:
        requests.post(f"{ZONE_URL}/api/tunnels/heartbeat", json={
            "api_key": API_KEY,
            "slug": slug
        })
        time.sleep(30)
except KeyboardInterrupt:
    requests.post(f"{ZONE_URL}/api/tunnels/disconnect", json={
        "api_key": API_KEY,
        "slug": slug
    })
    print("تم إغلاق النفق.")
```

### Node.js

```javascript
const axios = require("axios");

const API_KEY  = "zt_live_xxxxxxxxxxxxxxxx";
const ZONE_URL = "https://your-zone-url";
const PORT     = 3000;

async function start() {
    const { data } = await axios.post(`${ZONE_URL}/api/tunnels/register`, {
        api_key:    API_KEY,
        local_port: PORT,
        name:       "My Script"
    });

    if (!data.success) {
        console.error("فشل:", data.detail);
        return;
    }

    const { slug, url } = data.tunnel;
    console.log("رابطك العام:", url);

    setInterval(() => {
        axios.post(`${ZONE_URL}/api/tunnels/heartbeat`, {
            api_key: API_KEY,
            slug
        });
    }, 30000);
}

start();
```

## مرجع API

### المصادقة

كل الطلبات المحمية تتطلب مفتاح API. يمكن إرساله بإحدى الطريقتين:

في جسم الطلب:

```json
{
  "api_key": "zt_live_xxxxxxxxxxxxxxxx"
}
```

في الترويسة:

```
Authorization: Bearer zt_live_xxxxxxxxxxxxxxxx
```

### إدارة الأنفاق

**POST /api/tunnels/register**

إنشاء نفق جديد.

المدخلات:

| الحقل | النوع | الوصف |
|-------|-------|-------|
| api_key | نص | مفتاح API |
| local_port | رقم | منفذ السكربت المحلي |
| name | نص | اسم اختياري للنفق |

المخرجات:

```json
{
  "success": true,
  "tunnel": {
    "slug": "abc123",
    "url": "https://your-zone-url/p/abc123"
  }
}
```

**POST /api/tunnels/heartbeat**

إبقاء النفق نشطاً. يُرسل كل ثلاثين ثانية.

**POST /api/tunnels/disconnect**

إغلاق النفق وإلغاء الرابط العام.

**POST /api/tunnels/list**

عرض كل الأنفاق المرتبطة بحسابك.

### إدارة المفاتيح

**POST /api/keys**

إنشاء مفتاح API جديد.

**POST /api/keys/list**

عرض كل المفاتيح مع إحصائياتها.

**POST /api/keys/delete**

حذف مفتاح.

### المستخدم

**POST /api/user/me**

عرض معلومات حسابك الحالي.

**POST /api/user/update**

تحديث الاسم الأول أو الأخير.

**POST /api/stats**

عرض إحصائيات الاستخدام.

### المصادقة

| المسار | الوصف |
|--------|-------|
| POST /api/auth/send-code | إرسال كود تحقق |
| POST /api/auth/verify-code | التحقق من الكود |
| POST /api/auth/signup | إنشاء حساب جديد |
| POST /api/auth/login | تسجيل الدخول |
| POST /api/auth/forgot-password | طلب استعادة كلمة المرور |
| POST /api/auth/reset-password | إعادة تعيين كلمة المرور |

## الأمان

المنصة تطبّق طبقات حماية متعددة على مستوى الخادم:

**تحديد المعدل**

حد أقصى خمس رسائل تحقق في الساعة وخمس عشرة في اليوم لكل عنوان IP، مع فاصل زمني لا يقل عن ستين ثانية بين كل رسالتين.

**حظر العناوين**

يُحظر أي عنوان IP يخالف القواعد تلقائياً لمدة أربع وعشرين ساعة، وقد يصبح الحظر دائماً في حال تكرار المخالفات.

**تشفير الأكواد**

أكواد التحقق تُخزّن مشفّرة بخوارزمية SHA-256 مع ملح فريد، فلا يمكن قراءتها حتى في حال الوصول إلى قاعدة البيانات.

**الحماية من التخمين**

بعد خمس محاولات تسجيل دخول فاشلة يُقفل الحساب مؤقتاً مع تأخير أسّي متزايد.

**الحماية من إغراق البريد**

يكتشف النظام محاولات استخدام نفس البريد من عناوين متعددة، ويوقفها تلقائياً.

**تشفير الاتصال**

جميع الاتصالات تمر عبر TLS 1.3.

**لوحات التحكم**

اعرض بيانات من جهازك على لوحة تحكم يمكن الوصول إليها عن بُعد.

**الاختبار والعرض**

اعرض مشروعاً محلياً على عميل أو فريق دون نشره رسمياً.

## الأسئلة الشائعة

**هل الخدمة مجانية فعلاً؟**

نعم، مجانية بالكامل وغير ربحية. لا رسوم خفية ولا إعلانات.

**هل هناك حد لعدد الأنفاق؟**

لا، يمكنك إنشاء عدد غير محدود من الأنفاق عبر مفاتيح API متعددة.

**كيف يبقى النفق نشطاً؟**

طالما سكربتك يرسل نبضة (heartbeat) كل ثلاثين ثانية، يبقى النفق مفتوحاً.

**هل يمكنني استخدام الخدمة تجارياً؟**

نعم، بشرط الالتزام بالشروط والأحكام.

**ماذا يحدث إذا حُظر عنوان IP الخاص بي؟**

الحظر مؤقت في البداية ويزول تلقائياً بعد أربع وعشرين ساعة. في حال تكرار المخالفات قد يصبح دائماً.

**هل بياناتي آمنة؟**

نعم. لا نجمع سوى البريد الإلكتروني، ولا نشاركه مع أي طرف ثالث.
